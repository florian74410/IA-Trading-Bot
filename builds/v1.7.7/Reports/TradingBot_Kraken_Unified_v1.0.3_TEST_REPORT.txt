TradingBot Kraken Unified v1.0.3 — RAPPORT DE TEST
===================================================
Date : 2026-08-24

PROBLÈME CORRIGÉ
----------------
Kraken Public était déclaré connecté et le ticker fonctionnait, mais les bougies n'étaient pas
rendues dans le Chart.

CAUSE
-----
Kraken REST OHLC renvoie le timestamp Unix de chaque bougie en secondes.
Le format interne historique du TradingBot / GMX stocke les timestamps de bougies en millisecondes.
Le Chart convertit ensuite ce format interne en secondes pour Lightweight Charts.
En v1.0.2, les timestamps Kraken n'étaient pas convertis en millisecondes : ils étaient donc divisés
une seconde fois par 1000 côté graphique, créant des timestamps identiques ou quasi-identiques et
une série invalide.

CORRECTION v1.0.3
-----------------
- Conversion automatique des timestamps Kraken secondes -> millisecondes dans router.js.
- Compatibilité conservée si une source fournit déjà des millisecondes.
- Tri chronologique explicite des chandeliers Kraken.
- Déduplication par timestamp.
- Rejet des OHLC non numériques/incomplets.
- Réponse diagnostic : timestampUnit = "ms".
