Crypto Chart Viewer IA Trader — v1.5.1
ULTRA MODE v2.0 — intégration ADMIN

OBJECTIF
- Lier le Mode ULTRA au cycle de vie du VPS local IA-TB.
- Conserver ULTRA actif pendant un simple redémarrage IA-TB.
- Désactiver ULTRA lors d'un Arrêt Total / arrêt réel du VPS.

ARBORESCENCE
Core/Booster/ultra_mode/
  start.command
  stop.command
  status.command
  ultra_manager.js
  log.txt

PRÉFÉRENCE ADMIN
Parametres/UltraModeSettings.dat
- protégée par UpdateManager via Parametres/** ;
- absente = ULTRA au démarrage désactivé ;
- checkbox ADMIN = enabledOnStart true/false.

DÉMARRAGE
Si enabledOnStart=true :
1. status ULTRA ;
2. si déjà ACTIVE, ne pas relancer ;
3. sinon START ULTRA ;
4. attendre confirmation ACTIVE (timeout 10 s) ;
5. stabilisation 2 s ;
6. démarrer Kraken / Indicators / MarketData / Liquidity / Core / Router.

Si ULTRA ne se confirme pas lors d'un démarrage à froid, IA-TB continue en mode normal afin de ne pas rendre l'application indisponible. L'erreur est journalisée.

REDÉMARRAGE IA-TB
- si ULTRA est ACTIVE : il reste ACTIVE, aucun stop/start ;
- si enabledOnStart=true mais ULTRA est INACTIVE : activation + confirmation + 2 s, puis redémarrage ;
- si l'activation échoue pendant un redémarrage demandé depuis ADMIN, le redémarrage est refusé et IA-TB courant reste disponible.

ARRÊT TOTAL
1. réponse HTTP à l'ADMIN ;
2. arrêt Core/Launcher et services connus ;
3. stop ULTRA ;
4. préférence enabledOnStart conservée pour le prochain lancement.

SÉCURITÉ
- aucun shell interactif exposé dans ADMIN ;
- chemins et scripts ULTRA fixés dans le code ;
- aucune commande utilisateur injectée au shell ;
- WindowServer, kernel, SMC, XProtect, disk arbitration, trustd, VM/filesystem non touchés ;
- LaunchAgents ULTRA unloadés sans -w : modification session-only ;
- rollback UpdateManager 1.5.0 <- 1.5.1 disponible.

COMPATIBILITÉ MODE ULTRA AUTONOME
- status.command reconnaît également une session active du pack autonome ~/.macro_ultra_v2 ;
- aucun second Mode ULTRA n'est lancé si cette session est déjà active ;
- Arrêt Total / stop intégré peut restaurer proprement cette session autonome active.
