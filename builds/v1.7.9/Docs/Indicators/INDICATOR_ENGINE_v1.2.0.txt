Crypto Chart Viewer IA Trader — Indicator Engine v1.2.0
=======================================================

ARCHITECTURE
------------
Indicators/
  Engine/
    indicator_engine.js      Calcul mathématique pur
    indicator_registry.js    Registre déclaratif sûr
    indicator_service.js     Service local 127.0.0.1:8012
    indicator_ui.js          Interface ƒx Indicateurs
  BuiltIn/                   20 *.indicator.json
  Custom/                    JSON personnalisés sûrs
  Quarantine/                Custom invalides/refusés

FLUX
----
Navigateur :8000
   -> Router
      -> Core :8001 (application / GMX)
      -> Kraken :8011
      -> Indicator Engine :8012

Le Core trading ne charge pas le moteur d'indicateurs. Une panne du moteur ne
peut donc pas exécuter ni modifier un ordre. Le Router expose le moteur sous
/indicator-api/.

SÉCURITÉ
--------
- aucune dépendance npm ;
- aucun eval / Function / require depuis JSON ;
- operations mathématiques natives sur liste blanche ;
- service lié uniquement à 127.0.0.1 ;
- maximum 8 indicateurs par calcul ;
- maximum 600 bougies par contexte runtime ;
- fichiers Custom invalides déplacés dans Quarantine ;
- aucune fonction web d'import/suppression en v1.2.0.

AFFICHAGE
---------
Trading IA : calcul + lignes sur Lightweight Charts + panneau de valeurs.
Chart Viewer : panneau de calcul disponible sur la source Kraken. Le widget
TradingView externe reste intact pour préserver ses outils interactifs ; les
lignes calculées localement ne sont pas injectées dans l'iframe TradingView.

VOLUME
------
Kraken fournit le volume OHLC : MFI, OBV, VWAP, VWMA sont disponibles.
GMX Oracle ne fournit pas un volume de bougie fiable dans ce flux : ces quatre
indicateurs sont refusés proprement avec VOLUME_REQUIRED au lieu d'inventer une
donnée.
