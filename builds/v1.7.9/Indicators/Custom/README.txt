CUSTOM INDICATORS — v1.2.0
==========================

Dépose ici uniquement des fichiers *.indicator.json déclaratifs.
Aucun JavaScript n'est exécuté depuis ce dossier.

Un Custom doit :
- utiliser schema = iatb.indicator.v1 ;
- avoir un id unique ;
- référencer une operation native autorisée dans engine.operation ;
- respecter les bornes de paramètres du JSON.

Après ajout manuel, utiliser la commande de reload du registre ou redémarrer l'application.
Les fichiers invalides sont déplacés automatiquement dans ../Quarantine/.
