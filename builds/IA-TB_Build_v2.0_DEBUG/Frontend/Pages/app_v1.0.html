⇄ Communication Protocol & Router

Le Communication Protocol est un standard, pas un moteur. Le Router existant sur 127.0.0.1:8000 assure l’annuaire, le contrôle d’accès et le routage. Les commandes CP arbitraires exigent le secret interne local; l’interface n’expose que le diagnostic et un test fixe.

🔒 Sécurité locale CP/1

Actif dès la branche 1.x : whitelist des actions, validation JSON stricte, request_id, timestamp anti-rejeu, authentification inter-processus, limites de taille, timeouts et journal d’audit dans logs.dat. Les Engines restent liés à 127.0.0.1. TLS/mTLS et réseau privé seront ajoutés lors du passage VPS.
