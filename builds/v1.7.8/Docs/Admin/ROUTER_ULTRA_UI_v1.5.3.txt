Crypto Chart Viewer IA Trader — v1.5.3

CORRECTIF ADMIN

1. ROUTER — faux OFFLINE
Le registre Admin validait auparavant /router-health par recherche de la chaîne brute "router":true.
Le Router renvoie un JSON formaté pouvant contenir des espaces, par exemple "router": true.
La v1.5.3 parse désormais le JSON et valide strictement la propriété router === true.
Le PID, la version et les autres champs restent inchangés.

2. ULTRA — impression de temporisation en boucle
Le polling de statut ULTRA réécrivait toutes les quelques secondes le texte du bandeau de log avec
« stabilisation 2 s », pendant que le rafraîchissement du log écrivait à son tour le chemin et la taille.
Cette alternance visuelle pouvait donner l'impression que la temporisation était relancée.

La v1.5.3 supprime cette concurrence d'affichage :
- renderUltra ne modifie plus la métadonnée du journal ;
- loadUltraLog reste le seul propriétaire de ultraLogMeta ;
- le délai de 2 s reste appliqué une seule fois, uniquement lors d'une activation réelle d'ULTRA ;
- un redémarrage IA-TB avec ULTRA déjà actif conserve ULTRA sans temporisation.

Aucune logique système ULTRA, aucun secret, aucun portefeuille et aucune donnée utilisateur ne sont modifiés.
