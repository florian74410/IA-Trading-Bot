Crypto Chart Viewer IA Trader — v1.5.2
ULTRA Mode v2.0 — Correctif temporisation / redémarrage

OBJECTIF
- Supprimer l'impression de temporisation qui boucle.
- Garantir un seul cycle d'activation ULTRA par demande.
- Ne jamais temporiser quand ULTRA est déjà ACTIF.

LOGIQUE v1.5.2
1. Redémarrage IA-TB + ULTRA déjà ACTIF
   - status vérifié une fois ;
   - aucun stop/start ULTRA ;
   - aucune stabilisation ULTRA ;
   - redémarrage VPS immédiat.

2. Redémarrage IA-TB + ULTRA inactif + autostart ON
   - start.command exécuté une seule fois ;
   - status.command confirmé une seule fois au retour du START ;
   - temporisation de stabilisation exécutée une seule fois : 2000 ms ;
   - redémarrage IA-TB ensuite.

3. Requêtes concurrentes
   - ultra_manager utilise un verrou single-flight ;
   - une seconde demande pendant START ne déclenche pas un second START ;
   - elle attend le résultat du cycle déjà en cours.

4. Démarrage à froid start.command
   - suppression de la boucle 10 x 1 s ;
   - START shell synchrone ;
   - une seule confirmation status ;
   - un seul sleep 2 s si ACTIVE ;
   - fallback IA-TB normal si ULTRA non confirmé.

INCHANGÉ
- Arrêt Total arrête IA-TB puis ULTRA.
- Préférence Admin ULTRA au démarrage conservée.
- Scripts système ULTRA v2.0 inchangés.
- Portfolio / Trading / Engines inchangés.
