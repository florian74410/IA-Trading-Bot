## Correctif ChartViewer natif

Sur `/ia-trading`, les événements à horaire officiel utilisent le même espace
logique que les chandeliers, les dessins et les overlays d'indicateurs. Les
instants UTC, y compris les fractions de seconde, sont interpolés entre les
centres de bougies. Ils ne sont pas arrondis à l'ouverture d'une bougie.
Pan, zoom, marché, paire et timeframe recalculent les coordonnées.

Les lignes de 1,25 px, pointillées et d'opacité 0,38 vont du haut de la zone de
prix à l'axe temporel. CME est cyan `#5acfff`, FED jaune-orangé `#f6bf61`, Finance
Calendar mauve discret `#b4a6cf`. La source Finance Calendar reste distincte même
si son flux est transporté dans le champ historique `calendars.cme`. Seul un
identifiant fournisseur explicite FED/CME peut changer cette classification.
Le filtre historique Fundamental « CME » continue d'inclure ce flux par
compatibilité ; il ne change pas la provenance affichée.

Les badges proposent source, date/heure et décompte des événements simultanés.
Survol de ligne/badge, focus clavier ou toucher ouvrent les détails de tous les
événements du même instant. Échap referme l'infobulle. Les valeurs nulles sont
signalées « Indisponible », les valeurs zéro sont conservées. Les badges restent
focusables pendant les redessins. Les lignes n'interceptent aucune interaction.

Un clic sur le bandeau à venir centre l'événement dans la plage accessible. Le
pan autorise un espace futur de 90 jours, sans création de chandeliers,
volumes, points d'indicateur ou données fournisseur. Quand il n'y a plus de
bougies visibles, l'axe de prix reprend l'échelle de la dernière vraie bougie.
Un événement hors fenêtre reste hors fenêtre ; aucun badge n'est accroché à un
bord pour simuler sa présence. Le passé reste accessible dans les 5 000 bougies
maximum déjà chargées ; aucun téléchargement historique supplémentaire n'est ajouté.

Les dates sans heure officielle et les événements `allDay` restent uniquement
dans le bandeau. Les labels locaux ET/CT sont convertis selon les règles IANA ;
les heures ambiguës ou inexistantes lors d'un changement d'heure ne produisent
pas de ligne exacte. EST/EDT/CST/CDT explicites conservent leur décalage annoncé.
Les dates fournisseur sans indication UTC/décalage ne sont pas interprétées.

L'axe, les badges et l'infobulle partagent `controller.timeZone`, initialisé au
fuseau du navigateur. L'identifiant IANA est affiché sur le graphique et le
décalage UTC est précisé dans les détails. `setTimeZone(zone)` permet de changer
le fuseau sans changer les instants. Les préférences existantes par client sont
conservées ; le filtre moyenne/haute importance est également exposé.

## Chaîne examinée et sécurité

`calendar_provider.js` agrège FED, CME/Finance Calendar et expirations ;
`fundamental_service.js` expose déjà les calendriers complets via la lecture
CP/1 `fundamental.calendar.upcoming`. Le frontend exploite ces calendriers, ce
qui conserve les événements passés encore fournis malgré le nom « upcoming ».
Les contrats de ces deux fichiers sont conservés. Le provider Finance Calendar
rejette désormais les heures sans fuseau et les faux instants d'événements all-day.
Un échec de lecture efface les marqueurs précédents plutôt que de conserver des
données anciennes sans indication. Aucune permission Auth21, règle Firewall,
RiskGate ou configuration LIVE n'est modifiée.

`/chart-viewer` reste une iframe TradingView isolée. Ce correctif ne manipule
pas son DOM et n'y ajoute pas de marqueurs.

```bash
npm ci --prefix App --omit=dev --no-audit --no-fund
node App/Tools_validate_release_version.js
node --test tests/calendar_events_v2_2_5.test.cjs tests/chart_events_v251.test.cjs
```

Tests visuels avec la vraie page Trading IA et des réponses réseau contrôlées :

```bash
npm install --prefix /tmp/iatb-browser-qa playwright@1.62.1
/tmp/iatb-browser-qa/node_modules/.bin/playwright install --with-deps firefox
NODE_PATH=/tmp/iatb-browser-qa/node_modules IATB_QA_ARTIFACTS=/tmp/iatb-251-visual \
  node --test App/UI/Tests/test_chart_events_v251.js App/UI/Tests/test_v2_4_1_calendar_bank.js
```

Les tests comparent les pixels du Canvas avec/sans événements, inspectent les
couleurs réellement calculées, les badges, les détails et les coordonnées des
dessins. Ils couvrent aussi le vide, l'indisponibilité et le toucher. Aucun mock
d'identité ni garde-fou de production n'est ajouté pour cette qualification.
Le workflow complet hérité est activé sur `2.5.1` et conserve les suites Auth21,
Market Data, CP/1, Risk et Firefox. Les captures sont des artefacts CI temporaires.

## Recette avec flux réels

Sur la copie locale sécurisée `https://localhost:8000/ia-trading`, vérifier les
états des providers, puis comparer un événement réellement horodaté à son
payload CP/1 et à la source officielle. Tester 1m/5m/15m/1h/4h/1D, zoom/pan,
changement de paire et marché, clic d'un événement futur et outils de dessin.
Vérifier le fuseau du graphique, une date FED sans heure (aucune ligne), les
préférences Fundamental, le clavier et un appareil tactile.
L'absence d'heure officielle FED/CME ne doit jamais être compensée par une
heure habituelle supposée. La disponibilité actuelle des API et cette recette
sur données privées de l'installation restent à vérifier localement.
