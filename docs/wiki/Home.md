# IA-TB — Wiki

Bienvenue dans la documentation officielle de **IA-TB**.

IA-TB est une application de trading crypto modulaire réunissant notamment :

- connecteurs CEX / DEX ;
- Market Data ;
- Chart Viewer ;
- Indicator Engine ;
- Liquidity Engine ;
- configuration centralisée des API ;
- système de mise à jour versionné.

## Principe documentaire

Le Wiki décrit uniquement les fonctions réellement publiées. Toute nouvelle release passe par une analyse d'impact Wiki après son déploiement GitHub.

Chaque ajout d'un CEX ou DEX doit documenter ses marchés, OHLC/OHLCV, volumes, intégration Market Data, Chart Viewer et paramètres nécessaires dans `Settings > API`.
