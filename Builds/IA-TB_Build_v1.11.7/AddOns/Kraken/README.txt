KRAKEN ADD-ON ISOLE
===================
Cette variante ne modifie pas server_v1.0.js, app_v1.0.html, chart_viewer_v1.0.html ni launcher.js.
Le service Kraken tourne separement sur 127.0.0.1:8011.

1) Lance start.command pour verifier le TradingBot v1.0.
2) Lance AddOns/Kraken/start_kraken.command pour tester Kraken separement.
3) Ou lance start_with_kraken.command a la racine pour les deux services.

Cette premiere variante Add-On teste uniquement les donnees publiques Kraken sans cle API.
